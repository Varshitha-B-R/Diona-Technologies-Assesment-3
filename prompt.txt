Prompt 1 — PDF Understanding 

Think You are an expert in document analysis.

I will provide a PDF form. Your task is to deeply analyze and extract its full structure.

Output must be in structured JSON format with:
1. Sections (Header, Body, Tables, Footer)
2. Each field with:
   - label
   - type (text, date, checkbox, dropdown, number)
   - required (true/false)
   - placeholder/example value
3. Table structures:
   - column headers
   - row format
4. Layout hints:
   - alignment (left/right/center)
   - grouping of fields

Example Output:
{
  "header": {
    "title": "Worker Progress Report",
    "fields": [
      { "label": "Worker Name", "type": "text", "required": true }
    ]
  },
  "sections": [
    {
      "name": "Recovery",
      "fields": [
        { "label": "Pain Scale", "type": "number", "range": "1-10" }
      ]
    }
  ]
}

Do not skip any field. Preserve exact labels from PDF.
